NanaAudio Acoustic v1.1 Debug

Truyền file trực tiếp bằng loa ↔ microphone, không cần mạng. Bản này ưu tiên kiểm chứng đường truyền thực tế: packet + SHA-256 + CRC32 + OFDM, chạy trong một file HTML.

1. Cấu hình

Khuyến nghị lần đầu: FAST, khoảng cách 10–30 cm, âm lượng 50–75%. TURBO cần loa/mic tuyến tính và SNR tốt hơn.

2. Tự kiểm tra

chưa chạy
Kiểm tra CRC, packet, bitstream và mô phỏng OFDM qua kênh có noise + echo.

3. Gửi file

Chưa chọn file.

Để tránh treo trình duyệt, prototype tự chặn transmission quá 120 giây hoặc waveform vượt 32 MB. Giới hạn thực tế thay đổi theo profile.

4. Nhận file

Đặt micro gần loa rồi bấm “Bắt đầu thu”.

Trình duyệt sẽ hỏi quyền microphone. Nếu mở file:// mà điện thoại chặn micro, chạy cùng file này qua HTTPS hoặc localhost.

Thông số giao thức v1

48 kHz protocol clock · FFT 1024 · cyclic prefix 128 · 3 training symbols · pilots mỗi 12 carrier · equalization theo từng subcarrier · SHA-256 file · CRC32 toàn packet · UTF-8 filename/MIME. Không truyền KEY hay dữ liệu bí mật nào ngoài chính nội dung file. Đây là modem truyền dữ liệu, không phải lớp mã hóa bảo mật.
